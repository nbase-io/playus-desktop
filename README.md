# PLAYUS Desktop (Windows · macOS)

[PLAYUS](https://www.playus.app) 데스크톱 앱 설치 파일과 자동 업데이트 정보를 내보내는 곳입니다. 앱 소스는 이 저장소에 없습니다.
Installers and the auto-update feed for the PLAYUS desktop app. The app source is not in this repository.

- 맥 앱은 Apple 공증을 받았습니다. Notarized by Apple.
- 설치한 뒤에는 앱이 새 버전을 스스로 받아 다시 시작할 때 바뀝니다. Installed apps update themselves.
